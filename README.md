# Study Schedule Manager

A responsive study timetable app built with HTML, CSS and vanilla JavaScript.

## Features
- Add, edit and delete study activities
- Choose a date, category and start/end time
- Mark activities as complete or pending
- Daily planned-hours and completion statistics
- Progress bar and date filter
- Light/dark theme
- Data saved in browser LocalStorage

## Run locally
1. Download or clone this project.
2. Open the `study-schedule-manager` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No npm installation or backend is required.

## Technologies
HTML5 · CSS3 · JavaScript · LocalStorage
